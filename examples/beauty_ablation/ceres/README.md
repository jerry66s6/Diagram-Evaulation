# V3 measured iteration dashboards

These self-contained dashboards preserve the three measured v3 iterations.

The dashboards' internal model-route labels were replaced with
`internal vision judge`; no authentication, endpoint, or deployment metadata is
included. Scores, observations, reasoning, images, and isolation calculations
are otherwise preserved.

Iteration 3 is the latest completed measurement and reached 89.2/100 overall
isolation. The generator subsequently removed extra node borders from the Ink
Balance fixture, but that corrected fixture was not rerun because of a quota.
These dashboards therefore do not claim a result for the final fixture.
