What this run measures

  • Input: the dataset’s expanded_query, unchanged, and its original PNG. The PNG is the candidate being assessed; no new diagram is generated.
  • Expectation stage: one text-only call per example freezes the required components and connections. The image and reference code are withheld from this stage.
  • Scoring stage: one image call per example evaluates all five dimensions together using that frozen inventory. This is two planned calls per example, not five calls per image.
  • Mode: GPT image evaluation only. DiagramGen supplies PNGs and LaTeX/DOT code, so this pilot omits the SVG geometry judge and VFIG conversion.
  • Selection: 4 model-architecture-labeled examples, 4 flowcharts, and 2 directed graphs; seed 20260930, sorted by SHA256(seed + ':' + id) within each category. The dataset category labels are retained even where their meanings are broad.
  • Interpretation: reference images are not guaranteed perfect matches to expanded descriptions. Ten examples do not establish evaluator accuracy. Human review and controlled degradations would be needed to test sensitivity and compare judges.

Run or resume locally

Configure OPENAI_API_KEY in your local environment, then run this from the repository folder:

.venv/bin/python scripts/run_diagramgen10.py --live

Completed reports and frozen inventories are reused. The HTML is regenerated after each example. A changed evaluator configuration requires a fresh output directory.

Score calculation and limits

Presence is drawn components divided by decided components. Details is correctly labeled components divided by drawn components. Uncertain components are excluded from these denominators. Other criteria use (expected opportunities − detected issues) / expected opportunities. Zero opportunities are N/A. Criterion scores are averaged within each dimension, then the configured weights produce the overall score; available dimensions are renormalized. These weights come from this project’s existing sample issue history.

Descriptions that leave node counts or exact connections unspecified may yield ambiguous inventories. All source descriptions are retained for review. This run does not include the other team’s beauty metrics, repeated-judge uncertainty, or human accuracy labels.
