How to read this experiment

Measured scores, fixed comparison

Each variant is generated directly from the original SVG. All six are evaluated using the same rubric, frozen inventory, thresholds, and weights. Scores are calculated from detected issues; no cell is manually reduced.

Within each dimension, criterion scores are averaged. A failed reading-order check therefore affects one of three Layout criteria; a font-size failure affects one of two Legibility criteria. An absent component is excluded from the Details denominator.

Saved historical baseline

This prior result is retained for context. Changes in the matrix use only the baseline evaluated in this run with the same evaluator and expectations as its variants.

Scope and limitations

    Reproduce and extend

    Run from the repository root:

    python3 scripts/run_dimension_ablation.py

    To re-evaluate all six diagrams with the configured GPT judge and SVG evaluator, install the project dependencies, configure OPENAI_API_KEY, then run:

    PYTHONPATH=src python3 scripts/run_dimension_ablation.py --live

    The live run writes to a separate ablation-live folder. It needs six candidate-scoring calls and reuses the frozen description inventory.
